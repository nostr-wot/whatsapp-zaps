WhatsApp Zaps

Type /zap @name 1000 in a group, or /zap 1000 in a private chat, to send sats through your Nostr WoT wallet. These are the Lightning Addresses you have saved for contacts. Addresses you enter in a chat are saved here too. Everything here stays in this browser.

Find on Nostr

Search by name, npub or NIP-05 address and save the Lightning Address from their profile. Name searches go to public Nostr search relays.

Every chat

Used in any chat, unless a chat has its own entry below.

Single chats

Saved from a chat with “Remember for this chat”. These win over the list above in that chat.

Backup

Move your contacts to another browser as a JSON file.

Troubleshooting

If a mention or the message box does not work as it should, copy the diagnostics and send them to the developer. They contain the markup of WhatsApp's message box and mention list, including the names shown there. They stay in this browser until you copy them.
